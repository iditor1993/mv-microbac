# MV_microbac

Repository: https://github.com/iditor1993/mv-microbac

Analysis code for a two-database prediction-model study asking how much each layer of prior microbiological history adds — beyond prior antibiotic exposure — to the prediction of cefepime resistance in mechanically ventilated patients with Gram-negative lower respiratory tract infection.

**Study in brief.** Two retrospective cohorts (ARMD-MGB; MIMIC-IV v3.1) of adults receiving invasive ventilation with a lower respiratory culture growing a Gram-negative organism and tested for cefepime. Seven nested logistic models add demographics and organism group (M0), prior antibiotic exposure (M1), prior culture burden (M2), prior isolation of the same organism (M2b), prior cefepime susceptibility of that organism (M3), and history of other organisms (M4–M5). Discrimination is estimated by patient-grouped cross-validation (ARMD-MGB) and temporal validation (MIMIC-IV), with patient-clustered bootstrap, calibration, decision curves and a two-drug cascade simulation.

```text
│  ├─ s06_xgb_replication.py      gradient-boosted trees
│  ├─ s07_repeated_cv.py          repeated cross-validation (five seeds)
│  ├─ s08_exclusions.py           exclusion analyses
│  ├─ s09_mimic_severity.py       severity adjustment (MIMIC-IV)
│  ├─ s10_recalibration.py        recalibration in the large; yearly discrimination
│  ├─ s11_cross_database.py       cross-database transport
│  ├─ s12_recalibrated_thresholds.py
│  ├─ s13_coefficients.py         full model coefficients
│  ├─ s14_cascade.py              two-drug cascade simulation
│  ├─ s15_cascade_paired.py       paired comparisons between strategies
│  ├─ make_figures.py             all figures (300 dpi)

└─ results/                       generated, git-ignored (tables/ and figures/)
```

The repository deliberately contains **no manuscript files, no result figures or tables, no patient-level data and no source databases**. Everything in `results/` is regenerated by the scripts.

There is no `s03` script: the meropenem sensitivity analysis is the primary script run with different arguments (see below).

## Data

| Database | Content | Access |
|---|---|---|
| ARMD-MGB | De-identified Mass General Brigham microbiology, prescribing, procedure and demographic data linked at the culture-order level | PhysioNet credentialed access; cannot be redistributed |
| MIMIC-IV v3.1 | Beth Israel Deaconess Medical Center EHR, 2008–2022 | PhysioNet credentialed access |

Both are opened **read-only**; nothing is copied, exported or logged at the individual level.

Put the DuckDB files in `data/` at the project root, or point the environment variables at them:

```powershell
$env:MV_DATA_DIR = "D:\data\mv"            # both databases from one directory
$env:ARMD_DB     = "D:\data\ARMD_MGB.duckdb"
$env:MIMIC_DB    = "D:\data\mimiciv_v3_1.duckdb"
```

## Quick start

```powershell
python run_all.py --list                  # show the steps
python run_all.py                         # full pipeline
python run_all.py --only s10_recalibration.py
python run_all.py --include-meropenem     # also run the meropenem sensitivity analysis
```

Individual scripts can be run directly from `src/`:

```powershell
cd src
python s01_incremental_value.py
python s01_incremental_value.py --drug meropenem --tag s03_meropenem
python make_figures.py
```

## Pipeline

### Core

| Script | Purpose |
|---|---|
| `common.py` | Metrics (AUROC, AUPRC, Brier), calibration, NRI/IDI, net benefit, patient-clustered bootstrap |
| `features.py` | Cohort definitions and the five layers of prior history, identical in both databases |
| `analysis.py` | Nested models M0–M5, increments, stratification, thresholds, calibration bins |
| `s01_incremental_value.py` | **Primary analysis**: nested models, ΔAUROC, NRI/IDI, decision curves, calibration |

### Pre-specified sensitivity analyses

| Script | Analysis |
|---|---|
| `s02_site_decomposition.py` | Same-organism resistance from respiratory versus non-respiratory specimens |
| `s04_mv_window.py` | Ventilator procedure 1–2/7/14/30 days; invasive ventilation ±12/±24 h |
| `s05_phenotype_emulation.py` | ARMD-MGB ventilation proxy applied to MIMIC-IV and compared with the precise record |
| `s06_xgb_replication.py` | XGBoost instead of logistic regression |
| `s07_repeated_cv.py` | Five random seeds of patient-grouped cross-validation |
| `s08_exclusions.py` | Excluding cefepime in the prior 7 days; excluding polymicrobial cultures |
| `s09_mimic_severity.py` | First-day SOFA, vasopressors, lactate and Charlson index |
| `s10_recalibration.py` | Recalibration in the large; year-by-year discrimination |
| `s11_cross_database.py` | Each database's model applied to the other without refitting |
| `s12_recalibrated_thresholds.py` | Threshold performance after recalibration |
| `s13_coefficients.py` | Coefficients and odds ratios of the primary model |
| `s14_cascade.py` | Cascade simulation (cefepime → meropenem) |
| `s15_cascade_paired.py` | Paired differences between cascade strategies |

### Figures and feasibility

| Script | Purpose |
|---|---|
| `make_figures.py` | Figure 1 ROC curves, Figure 2 calibration, Figure 3 decision curves, Figure 4 increments, Figure 5 cascade trade-off, Figure S1 AUROC forest, Figure S2 learner comparison |
| `feasibility_probe.py` | Cohort sizes, ventilation ascertainment and prior-history availability |

## Reproducibility notes

- Random seeds are fixed (`20261024`) for cross-validation splits, bootstrap resampling and XGBoost.
- Bootstrap confidence intervals are clustered by patient throughout.
- No variable selection and no hyperparameter tuning are applied to the primary models.
- Missing exposure values use fixed sentinels so that variable definitions are identical across databases.
- Models are fitted on standardised features; coefficients are reported per standard deviation.
